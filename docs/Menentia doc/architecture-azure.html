Comment Mercure Tech héberge son site et l'écosystème ClientlyX : services utilisés, flux, sécurité, déploiement et coûts. Une architecture qui démarre petit et grandit sans être refaite.

Vue d'ensemble

Schéma de l'architecture

Lecture : chaque requête passe par Front Door, puis vers le site statique ou l'application. Les envois WhatsApp et les tâches de nuit tournent à part, dans Container Apps, sur la même image que l'application.

Confiance

Sécurité et continuité

Données protégées

  • Base de données sur réseau privé, jamais exposée
  • Identifiants WhatsApp chiffrés et secrets dans Key Vault
  • Accès des services par identité managée, sans mot de passe

Trafic filtré

  • HTTPS partout, pare-feu web devant l'application
  • Webhooks WhatsApp signés et vérifiés
  • Quotas contre les abus sur les pages publiques

Continuité

  • Sauvegardes de la base de 7 à 35 jours
  • Mise en production sans coupure par bascule d'emplacement
  • Retour arrière immédiat en cas de problème

Supervision

  • Alertes sur erreurs, lenteurs et file bloquée
  • Journal d'audit dans l'application
  • Jamais de remise à zéro de la base en production
